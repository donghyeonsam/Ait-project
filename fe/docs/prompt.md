# Ait — 대시보드 · AI 모의면접 · 리포트 모달 구현

첨부한 스크린샷 4장을 픽셀 수준으로 참고하여 아래 화면들을 구현해라.

- **이미지 1**: 대시보드 홈
- **이미지 2**: 태그 컬러 시스템 (면접유형 / 직무유형)
- **이미지 3**: AI 모의면접 페이지 (면접 기록 목록)
- **이미지 4**: 면접 리포트 모달

## 기술 스택 및 공통 규칙

- React + Tailwind CSS + shadcn/ui + lucide-react
- 폰트: Pretendard (전역 적용)
- 차트: 커스텀 SVG 또는 Recharts (단, 아래 애니메이션 스펙을 정확히 구현할 수 있는 방식을 선택할 것)
- 컴포넌트는 재사용 가능하게 분리할 것 (StatCard, ScoreTrendChart, InterviewRecordItem, TagBadge, ReportModal 등)
- 반응형은 데스크톱(1440px 기준) 우선, 최소 1024px까지 레이아웃이 깨지지 않게
- 모든 텍스트, 수치, 날짜는 스크린샷의 값을 그대로 목데이터로 사용

## 화면 흐름 (라우팅)

1. **대시보드 홈** (`/dashboard`, 이미지 1)
   - "최근 AI면접 기록" 카드의 **[전체 보기 >]** 클릭 → AI 모의면접 페이지로 이동
2. **AI 모의면접 페이지** (`/interviews`, 이미지 3)
   - 각 기록 카드의 **[리포트 보기]** 버튼 클릭 → 리포트 모달 오픈
3. **리포트 모달** (이미지 4)
   - **너비 960px, 높이 88vh 고정**, 내부 콘텐츠는 세로 스크롤
   - 오버레이 클릭 / [닫기] 버튼 / ESC 키로 닫힘
   - [다시 연습하기], [영상 다시보기]는 현재 동작 없이 버튼만 구현

## 화면별 상세 스펙

### 1. 대시보드 홈 (이미지 1)

- 상단 헤더: 로고(Ait) + 네비게이션(대시보드 / AI 모의면접 / 스터디 라운지 / 커뮤니티) + 알림 아이콘 + 프로필 아바타. 현재 페이지 메뉴는 활성 스타일 처리
- 인사 영역: "좋은 아침이에요, OO님" + 서브 문구
- 통계 카드 4개 (아이콘 + 라벨 + 수치 + "지난 주 대비 ▲n" 델타):
  - 이번 주 모의면접 4회 (▲1회) / 최근 모의면접 종합점수 8.7점 (▲1.2점) / 누적 스터디 횟수 18회 (▲4회) / 목표 달성률 78% (▲8%)
  - 델타는 빨간색 상승 표기
  - 감소는 파란색 하강 표기
- 최근 AI면접 기록: 점수 원형 배지(8.7 / 7.5 / 7.1) + 날짜 + 태그 2개(면접유형 + 난이도). 우측 상단 "전체 보기 >" 링크
- 종합 점수 추이: 꺾은선 차트. x축 07.09~07.21, 데이터 5.5 → 6.9 → 6.0 → 7.1 → 7.5 → 8.7, 각 포인트 위에 수치 라벨
- 최근 스터디 기록: 기업 로고 + 스터디명 + FE 태그 + 날짜 (NAVER / kakao / 삼성전자DX)
- 나의 스터디 일정: 좌측 "다가오는 일정" 리스트(D-2, D-5 배지) + 우측 7월 달력(일정 있는 날짜에 점 표시, 오늘 날짜 강조)
- 푸터: 로고 + 슬로건 + 링크 3개 + 카피라이트

### 2. AI 모의면접 페이지 (이미지 3)

- 페이지 타이틀 "AI 모의면접" + 서브 문구
- 좌측 통계 카드 2개(세로 배치): 이번 주 모의면접 4회 / 연속 연습 1일 (최고 기록 7일)
- 우측 종합 점수 추이 차트: 대시보드와 동일 데이터, 단 **선 아래에 파란 그라데이션 영역 채움**이 있음
- AI 면접기록 섹션:
  - 면접 유형 필터 pill: 전체 / 종합 / 직무 / 기술 / 포폴 / CS — 단일 선택, 선택된 pill은 진한 배경(스크린샷의 CS 선택 상태 참고)
  - 세부 분야 드롭다운(전체 분야) + 정렬 드롭다운(최신순)
  - 기록 카드: 날짜 + 면접유형 배지 + 제목("프론트엔드 직무 면접") + 우측에 점수(크게) + "▲ +n점 지난 면접 대비" + [리포트 보기] 버튼
  - 필터 변경 시 목록이 실제로 필터링되도록 목데이터 6~8건 구성 (유형 다양하게)

### 3. 리포트 모달 (이미지 4)

- 헤더: "프론트엔드 직무 면접" + 메타(2026. 07. 21 · 직무 면접 · 24분 18초)
- 상단 2분할:
  - 좌측 종합 점수: **8.7** / 10 (8.7은 골드 컬러, 크게) + "▲ 이전보다 1.2점 상승"
  - 우측 역량 분석: 6축 방사형(레이더) 차트 — 축: 직무 역량, 논리성, 전달력, 시선처리, 답변 구조, (상단 1축은 임의 지정)
- 피드백 카드 2개 나란히:
  - 잘한 점 (초록 테두리/배경, 👍 아이콘) — 불릿 2개
  - 개선하면 좋은 점 (주황 테두리/배경) — 불릿 2개
- 질문별 피드백 (아코디언):
  - Q1은 펼침 상태로 시작 — 내부는 **내 답변 / 근거 / 연습 제안** 3컬럼, 세로 구분선
  - Q2 이후는 접힘 상태, 클릭 시 부드럽게 펼쳐짐
- 하단 고지 문구: "AI 분석 결과는 면접 연습을 위한 참고 자료입니다."
- 푸터 바: 좌측 [▶ 영상 다시보기] / 우측 [닫기] [다시 연습하기(네이비 primary)]

## 태그 컬러 시스템 (이미지 2)

TagBadge 컴포넌트 하나로 variant를 받아 처리하고, 색은 스크린샷 기준으로 토큰화해라.

**면접유형**: 직무(연파랑 bg/파랑 text) · 기술(연보라/보라) · 포폴(연노랑/골드) · CS(연분홍/빨강) · 종합(회색 bg/흰 text)

**직무유형**: FE(연분홍/빨강) · BE(연파랑/네이비) · AI(연보라/보라) · Data(진초록 bg/흰 text) · Infra(보라 bg/흰 text) · 보안(진빨강 bg/흰 text) · QA(회색 bg/흰 text) · Mobile(청록 bg/흰 text) · PM/PO(연회색/짙은 회색)

## 애니메이션 스펙 (중요)

라이브 데모용이므로 애니메이션 완성도가 핵심이다. 아래를 정확히 구현해라.

### 필수

1. **꺾은선 차트 (대시보드 + AI 모의면접 페이지 공통)**
   - 화면에 나타날 때 **꺾은선만 왼쪽에서 오른쪽으로 그려지는 슬라이드 애니메이션**
   - 구현: SVG path의 `stroke-dasharray` / `stroke-dashoffset` 트랜지션 또는 좌→우 clip-path reveal, 약 1.2s ease-out
   - 데이터 포인트(점)와 수치 라벨은 선이 해당 지점을 지나간 뒤 순차적으로 fade-in (stagger)
   - AI 모의면접 페이지의 그라데이션 영역 채움은 선이 다 그려진 뒤 아래에서 fade-in
   - 스크롤로 뷰포트에 들어올 때 1회만 재생 (IntersectionObserver)

2. **방사형(레이더) 차트 (리포트 모달)**
   - 모달이 열리면 데이터 폴리곤이 **중앙에서 바깥쪽으로 퍼지며 확장** (scale 0 → 1, transform-origin: center, 약 0.8s ease-out, 살짝 overshoot 되는 spring 느낌 권장)
   - 배경 그리드/축은 먼저 표시, 축 라벨은 폴리곤 확장 후 fade-in

### 추가 (권장)

3. **통계 카드**: 페이지 로드 시 순차 stagger로 fade-in + 아래에서 위로 살짝 올라오는 모션(translateY 12px → 0, 카드당 80ms 간격). 수치는 0부터 목표값까지 count-up (0.8s), 델타 배지는 count-up 완료 후 pop-in
4. **리포트 모달 오픈**: 오버레이 fade-in(배경 살짝 blur) + 모달 본체 scale 0.96 → 1 + fade, 0.25s. 닫힐 때 역재생
5. **모달 내 종합 점수 8.7**: count-up 애니메이션 (0 → 8.7, 소수점 유지)
6. **면접 기록 리스트 / 최근 기록 리스트**: 항목 stagger fade-in. 필터 변경 시에도 새 목록이 stagger로 재등장
7. **아코디언**: height 트랜지션으로 부드럽게 펼침/접힘, 화살표 아이콘 회전
8. **호버**: 카드류 hover 시 살짝 lift(shadow 강화 + translateY -2px), 버튼 hover 트랜지션
9. **접근성**: `prefers-reduced-motion` 설정 시 모든 모션 비활성화하고 최종 상태로 즉시 렌더

## 완료 기준

- 스크린샷과 나란히 놓고 비교했을 때 레이아웃·간격·컬러가 거의 동일할 것
- 대시보드 → 전체 보기 → 리포트 보기 → 모달 닫기 흐름이 끊김 없이 동작할 것
- 애니메이션이 재실행(라우트 재진입, 모달 재오픈) 시에도 정상 재생될 것
- 콘솔 에러 0건
