# Ait Logo Assets

AI 모의면접 서비스 **Ait**의 공식 로고 에셋입니다.

## Brand colors

- Primary Navy: `#1A2A4A`
- Accent Gold: `#C9A96E`

## Folder guide

- `primary/`: 기본 가로형 로고
- `symbol/`: 프레임·A·웹캠으로 구성된 심볼 단독
- `wordmark/`: 사람형 `i`와 골드 넥타이가 포함된 `Ait` 워드마크
- `favicon/`: 브라우저 파비콘
- `app-icon/`: PWA 및 앱 아이콘
- `web/`: 웹 최적화 WebP

## Recommended use

- 웹 헤더: `primary/ait-logo-horizontal.svg` 또는 `primary/ait-logo-horizontal-1024.png`
- Figma: SVG 파일을 드래그하여 가져오기
- 브라우저: `favicon/favicon.ico`
- PWA: `app-icon/ait-app-icon-192.png`, `app-icon/ait-app-icon-512.png`

## Clear space

로고 주변에는 상단 웹캠 렌즈 지름 이상의 여백을 유지하세요.

## Notes

- 모든 PNG는 투명 배경입니다.
- SVG는 확정된 로고 외형을 정확하게 보존하는 self-contained 형식입니다.
- 색상 변경, 비율 변형, 그림자 및 그라데이션 추가는 권장하지 않습니다.
