# Ait Landing Page Package

This package contains the full visual asset set and the Codex implementation
prompt for the Ait landing page.

## Contents

- `CODEX_PROMPT.md`: paste into Codex with this package and both reference images.
- `ASSET_MANIFEST.md`: asset purpose and usage notes.
- `assets-preview.png`: quick preview of the three fictional participant assets.
- `public/assets/landing/`: production-ready image and SVG assets.
- `references/`: the approved landing mockup and Ait design system.

## Suggested workflow

1. Copy `public/assets/landing` into the existing project's `public/assets/`.
2. Attach or keep the two files in `references/` available to Codex.
3. Paste `CODEX_PROMPT.md` into Codex.
4. Let Codex inspect the existing repository before it changes code.
5. Verify desktop, tablet, mobile, keyboard navigation, and reduced-motion mode.

The visual system deliberately avoids bright blue, cyan, purple, and neon
effects. Motion should create polish through timing, depth, and staging rather
than saturated color.
